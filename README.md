# Cálculo y Estadística

Repositorio para material de estudio de:
- Cálculo Diferencial e Integral
- Probabilidad y Estadística 1

## Estructura del proyecto
```
calculo-estadistica/
├── calculo/          # Scripts de cálculo diferencial e integral
├── estadistica/      # Scripts de probabilidad y estadística
└── utils/            # Utilidades compartidas
```

## Librerías utilizadas

- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- SymPy
- Jupyter
